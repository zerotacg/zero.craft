# Zero Craft Development Guidelines

This document provides guidelines for developing and testing the Zero Craft project.

## Many More Much Smaller Steps

As described in [Many More Much Smaller Steps](https://www.geepawhill.org/series/many-more-much-smaller-steps/) it is beneficial
to work in small steps

- Break down the problem into the smallest possible parts
- Address only one part at a time
- Start with the simplest implementation that could work
- Check with me after each component before moving to the next
- Prioritize working code over completeness
- Make each step small enough that it can be fully understood in isolation

## Build/Configuration Instructions

### Prerequisites

- Node.js and npm (for Cypress tests)

### Building the Project

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Build the project**:
   ```bash
   npm run build
   ```
